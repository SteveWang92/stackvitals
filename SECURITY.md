# Security Policy

This is a personal project maintained by a single developer. There is no dedicated security team or bug bounty program, but reports are welcome and will be looked at.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately instead, via either:

- GitHub's private vulnerability reporting: https://github.com/SteveWang92/stackvitals/security/advisories/new
- Email: contact@stevewang.me

Please include a description of the issue, steps to reproduce, and the potential impact where known.

## Response

There's no formal SLA — expect an acknowledgement within a few days. Fixes are prioritized by severity and released when ready.

## Supported Versions

Only the latest released version receives security fixes.

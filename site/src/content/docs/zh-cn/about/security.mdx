## 报告漏洞

请**不要**为安全漏洞创建公开的 GitHub issue。

请通过以下方式之一进行私密报告：

- [GitHub 私密漏洞报告](https://github.com/SteveWang92/stackvitals/security/advisories/new)
- 邮件：contact@stevewang.me

请包含问题描述、复现步骤以及已知的潜在影响。

## 响应

没有正式的 SLA——预计在几天内收到确认。修复按严重程度优先处理，准备好后发布。

## 支持的版本

只有最新发布的版本会收到安全修复。
